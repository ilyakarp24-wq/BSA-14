### Поток 1: Данные о новых заказах от магазинов
**Название:** Данные о новых заказах  
**Назначение:** Передача информации о заказе для маршрутизации  
**Направление:** В систему  
**Блоки и вложенность:**  
- `Order` (обязательный)  
  - `OrderId` (обязательный)  
  - `ShopInfo` (обязательный)  
  - `DeliveryInfo` (обязательный)  
  - `Items` (обязательный, массив)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| OrderId | String | 36 | Да | UUID, уникальный идентификатор заказа |
| ShopId | String | 36 | Да | UUID идентификатора магазина |
| ShopAddress | String | 255 | Да | Адрес точки комплектации |
| CustomerAddress | String | 255 | Да | Адрес доставки (должен быть в базе адресов) |
| DesiredTime | DateTime | - | Да | Желаемое время доставки (не ранее текущего + 30 мин) |
| ItemName | String | 100 | Да | Наименование позиции в заказе |
| ItemQuantity | Integer | - | Да | > 0 |

### Поток 2: База адресов комплектации заказов
**Название:** Справочник адресов комплектации  
**Назначение:** Первоначальное наполнение справочника адресов  
**Направление:** В систему  
**Блоки и вложенность:**  
- `AddressBook` (обязательный)  
  - `AddressRecord` (обязательный, массив)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| AddressId | String | 36 | Да | UUID адреса |
| FullAddress | String | 500 | Да | Полный текстовый адрес |
| GeoLat | Decimal | - | Нет | Широта (от -90 до 90) |
| GeoLon | Decimal | - | Нет | Долгота (от -180 до 180) |

### Поток 3: Статусы действий курьера
**Название:** Обновление статуса заказа  
**Назначение:** Оперативное отслеживание этапа выполнения заказа  
**Направление:** В систему  
**Блоки и вложенность:**  
- `StatusUpdate` (обязательный)  
  - `OrderId` (обязательный)  
  - `CourierId` (обязательный)  
  - `Status` (обязательный)  
  - `Timestamp` (обязательный)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| OrderId | String | 36 | Да | UUID заказа |
| CourierId | String | 36 | Да | UUID курьера |
| Status | Enum | 50 | Да | Допустимые значения: 'ACCEPTED', 'PICKED_UP', 'DELIVERED', 'CANCELLED' |
| Timestamp | DateTime | - | Да | Время события (не может быть в будущем) |
| Comment | String | 255 | Нет | Комментарий курьера (например, причина отмены) |

### Поток 4: Данные о поступивших заказах для расчетов с поставщиками
**Название:** Реестр заказов для поставщиков  
**Назначение:** Передача данных для расчета стоимости услуг доставки с поставщиком  
**Направление:** Из системы  
**Блоки и вложенность:**  
- `SupplierReport` (обязательный)  
  - `OrderId` (обязательный)  
  - `ShopId` (обязательный)  
  - `DeliveryCost` (обязательный)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| OrderId | String | 36 | Да | UUID заказа |
| ShopId | String | 36 | Да | UUID магазина |
| DeliveryCost | Decimal | - | Да | Стоимость доставки (>= 0, 2 знака после запятой) |
| OrderDate | Date | - | Да | Дата создания заказа |

### Поток 5: Данные о факте доставки заказа
**Название:** Подтверждение доставки для расчета ЗП  
**Назначение:** Инициация расчета вознаграждения курьера  
**Направление:** Из системы  
**Блоки и вложенность:**  
- `DeliveryConfirmation` (обязательный)  
  - `OrderId` (обязательный)  
  - `CourierId` (обязательный)  
  - `CompletionTime` (обязательный)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| OrderId | String | 36 | Да | UUID заказа |
| CourierId | String | 36 | Да | UUID курьера |
| CompletionTime | DateTime | - | Да | Фактическое время завершения доставки |
| DistanceKm | Decimal | - | Нет | Пройденное расстояние (>= 0, 2 знака после запятой) |

### Поток 6: Данные о начисленной оплате курьеру
**Название:** Начисления курьеру  
**Назначение:** Отображение финансовой информации в личном кабинете курьера  
**Направление:** В систему  
**Блоки и вложенность:**  
- `CourierPayment` (обязательный)  
  - `CourierId` (обязательный)  
  - `OrderId` (обязательный)  
  - `Amount` (обязательный)  

| Название атрибута | Тип данных | Длина | Обязательность | Ограничения или условия |
|-------------------|------------|-------|----------------|-------------------------|
| CourierId | String | 36 | Да | UUID курьера |
| OrderId | String | 36 | Да | UUID заказа, за который произведено начисление |
| Amount | Decimal | - | Да | Сумма начисления (>= 0, 2 знака после запятой) |
| PaymentDate | DateTime | - | Да | Дата и время начисления |
